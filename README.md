# 🚀 Hero Dev Portfolio

> **Clean, Simple, and Slick Web Design.**

Naim x Official is a modern, responsive personal portfolio website designed to showcase professional experience, technical skills, and educational background. It serves as a digital resume and a central hub for clients and recruiters to connect, featuring a clean layout with striking orange accents.

🌐 **Live Site:** *https://naimxofficial.github.io/Hero-Dev-Portfolio/*

---

## ✨ Features

| Feature | Details |
|--------|---------|
| 🏠 **Hero Section** | Split layout banner with a greeting, brief intro, profile image, and prominent "Download CV" & "Contact" buttons. |
| 👤 **About Me** | Clean summary block with quick-reference info cards for Name, Email, Date of Birth, and Location. |
| 💻 **Skills Matrix** | 4 beautifully styled skill cards highlighting core competencies: Vanilla JavaScript, React, Node.js, and MongoDB. |
| 📄 **Interactive Resume** | Side-by-side Education and Experience timelines detailing past roles and degrees, separated by clean horizontal rules. |
| 📬 **Contact Footer** | Split-design footer featuring social media links (Facebook, X, Instagram) alongside a clean, user-friendly message form. |
| 🎨 **Vibrant Theme** | Consistent energetic orange accent (`#FD6E0A`) paired with a soft off-white (`#FFF8F3`) background for optimal readability. |
| 🔤 **Modern Typography** | Utilizes the "Open Sans" font family for a professional, highly legible text hierarchy. |
